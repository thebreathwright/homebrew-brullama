# Brullama Homebrew Tap

This tap publishes the `brullama` Homebrew formula.

- Formula: [`Formula/brullama.rb`](Formula/brullama.rb)
- Scope: CLI/runtime
- Install with Homebrew 6.0.0 tap trust as needed

## Install

```shell
brew tap thebreathwright/brullama
brew trust --formula thebreathwright/brullama/brullama
brew install brullama
```
